# CloudCost AI – Application Screenshots

This directory contains visual captures of the CloudCost AI platform for documentation and portfolio presentation.

## Required Screenshots & Capture Guidelines

When capturing screenshots, ensure the application is running with sample seed data (`sample_data/seed_data.sql` and `sample_data/sample_billing_upload.csv`) in enterprise dark mode.

| Filename | Page / Route | What to Capture |
| :--- | :--- | :--- |
| `dashboard.png` | `/` (Dashboard) | Primary KPI ribbon, MoM expenditure variance chart, multi-cloud spend distribution, and recent anomalies table. |
| `cloud-accounts.png` | `/cloud-accounts` | Connected AWS, Azure, and GCP provider cards, connection status pills, and the "Connect Credentials" modal. |
| `cost-analytics.png` | `/analytics` | FinOps Analytics console, spending trends (daily/weekly/monthly), service breakdown chart, and forecast projections with 95% CI. |
| `billing.png` | `/billing` | Paginated billing line-items table, currency indicators, provider badges, and the CSV upload modal. |
| `anomaly-detection.png` | `/anomalies` | Statistical anomaly feed, Z-Score and spending spike severity badges, filters, and slide-over diagnostic inspection drawer. |
| `cost-optimization.png` | `/optimization` | Rightsizing recommendations, potential vs realized savings cards, idle resources table, and commitment planning tools. |
| `reports.png` | `/reports` | Enterprise report generator wizard, 1-click export templates, and generated reports archive with download buttons. |
| `settings.png` | `/settings` | Tenant organization profile, team members directory, role promotion/demotion dropdowns, and immutable audit log explorer. |

## Recommended Specifications
- **Resolution**: 1920x1080 (1080p) or 2560x1440 (1440p)
- **Format**: PNG (lossless)
- **Browser Theme**: Chrome / Edge dark theme, full viewport width
